# Аггрегации

## Обзор

Агрегации позволяют вычислять статистические значения по полям документов, которые соответствуют запросу. seq-db поддерживает различные функции агрегации:

- `AGG_FUNC_SUM` — сумма значений поля
- `AGG_FUNC_AVG` — среднее значение поля
- `AGG_FUNC_MIN` — минимальное значение поля
- `AGG_FUNC_MAX` — максимальное значение поля
- `AGG_FUNC_QUANTILE` — вычисление квантиля для поля
- `AGG_FUNC_UNIQUE` — вычисление уникальных значений поля (не поддерживается в временных рядах)
- `AGG_FUNC_COUNT` — подсчет количества документов в группе

Для ознакомления с API функций обратитесь к [публичному API](10-public-api.md#примеры-агрегаций)
